## Agent Brief

**Category:** enhancement (visual consistency + polish)

**Summary:** On the Reference Data screen, every category's active options render as pill-shaped
"tablets" with the sandy `--dot-beige` background and small icon buttons (move up/down, edit,
retire) — but the Coating category's two extra sub-lists, **Pairings** and **Exclusions** (both
only shown for `ReferenceDataCategory.Coating`), render their rows as plain unstyled flex rows
with no background at all, just an inline "×" remove icon. The reporter called out Exclusions
specifically; Pairings has the identical gap directly above it in the same file and is worth fixing
alongside it rather than leaving one inconsistent with the other.

**Current behavior:**
- Normal option tablets: `Views/ReferenceData/Index.cshtml:38` —
  `<span class="dg-badge" style="background:var(--dot-beige); ...">` with up/down/pencil/cross
  icon buttons at `font-size:11-13px`.

  align-items:center; gap:6px; font-size:13px;">`, no background, just a "×" remove button.
- Exclusion rows: `Views/ReferenceData/Index.cshtml:152-161` — same plain-`<div>` pattern as
  Pairings.

**Desired behavior:**
- Both Pairing and Exclusion rows adopt the same `dg-badge` sandy-background pill treatment as the
  normal option tablets (`background:var(--dot-beige)`, same padding/pill shape), so the whole
  Reference Data screen reads as one consistent component rather than two different ones.
- Across all of these — normal option tablets and the pairing/exclusion rows alike — the
  up/down/pencil/×  icon buttons increase from their current 11–13px to a more legible size (e.g.
  ~16px), while keeping them visually as icon-only buttons (no added background/border) so they
  don't start competing with the primary action buttons.

**Key interfaces:**

- `.dg-badge` class definition in `src/DotGlasses.Web/wwwroot/css/dot-glasses.css` (confirm exact
  padding/radius so Pairings/Exclusions match pixel-for-pixel, not just approximately)

**Acceptance criteria:**
- [ ] Pairing rows and Exclusion rows render with the same sandy-badge (`dg-badge`,
      `background:var(--dot-beige)`) pill styling as the normal option tablets on the same screen.
- [ ] The move-up/move-down/edit/retire icons on normal option tablets, and the remove ("×") icons
      on Pairings/Exclusions, are visibly larger than today (roughly 16px vs. the current 11–13px).
