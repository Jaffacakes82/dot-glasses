# 09 — Sign-out icon is small and doesn't read as "sign out"

Source: Admin Portal non-prod testing, 2026-09-09, Joe — "The 'sign out' icon is really small, and

## Agent Brief

**Category:** enhancement (UI polish)

**Summary:** The sign-out control in the sidebar's user chip renders the character `&#9099;`
(U+238B, "⎋" — the broken-circle "escape key" glyph) at 16px. It's both small and not a symbol
people associate with signing out.

**Current behavior:**
`src/DotGlasses.Web/Views/Shared/_Layout.cshtml:90-98`:
```html
@* AccountController.Logout has existed since the portal was built but nothing
   ever posted to it, so there was no way to end a session short of clearing
   cookies. *@
<form asp-controller="Account" asp-action="Logout" method="post" style="margin:0;">
    <button type="submit" title="Sign out" aria-label="Sign out"
            style="border:none; background:none; cursor:pointer; padding:4px; color:inherit; opacity:0.7; font-size:16px; line-height:1;">
        &#9099;
    </button>
</form>
```

**Desired behavior:**
Replace `&#9099;` with a door/exit-style glyph — e.g. the 🚪 door emoji, or a Unicode/box-drawing
"exit" glyph if an emoji reads as too playful for the admin chrome — and increase the size (e.g.
~20-22px, up from 16px) so it's clearly legible as its own affordance next to the avatar. Keep the
existing `title`/`aria-label="Sign out"` and hover/opacity treatment (`opacity:0.7` on rest,
already present) — only the glyph and its size are in scope.

**Key interfaces:**
- `src/DotGlasses.Web/Views/Shared/_Layout.cshtml:93-98`

**Acceptance criteria:**
- [ ] The sign-out control uses a door/exit-associated glyph instead of `&#9099;`.
- [ ] The glyph renders visibly larger than the current 16px.
- [ ] `title`/`aria-label="Sign out"` and the existing click behavior (posts to
      `Account/Logout`) are unchanged.
- [ ] The control still fits comfortably in the user chip alongside the avatar at both the
      desktop sidebar layout and the collapsed mobile top-bar layout (see ticket 08 — check after
      that ticket lands, since it touches the same chip's surrounding layout).

**Out of scope:**
- Any change to the sign-out *behavior* (`AccountController.Logout`, session/cookie clearing).
- The rest of the user chip (avatar initials, name, role label).
