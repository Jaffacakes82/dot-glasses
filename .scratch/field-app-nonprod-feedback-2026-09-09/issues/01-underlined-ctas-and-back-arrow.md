# 01 — Home action tiles and back-arrow links show a browser-default underline

Status: ready-for-agent
Blocked by: None — can start immediately
Category: bug

Source: Field App non-prod testing, 2026-09-09, Joe — "All the call to actions in the field app
are underlined" + "Back arrow call to action has an underline."

## Agent Brief

**Category:** bug (CSS)

**Summary:** Two anchor-based components in the Field App's design system never got a
`text-decoration: none` reset, unlike every `<a class="dg-btn ...">` link, which already inherits
it from `.dg-btn` (`src/DotGlasses.App/wwwroot/css/dot-glasses.css:178`). Both render with the
browser's default link underline.

**Current behavior:**
- `.dg-action-tile` (`dot-glasses.css:139-150`) styles the four big Home-screen CTAs (Record
  Test/Lead/Sale, Leads — all `<a class="dg-action-tile" ...>` in
  `src/DotGlasses.App/Pages/Home.razor:50-65`) but sets no `text-decoration`, so all four render
  underlined.
- `.dg-top-strip .back` (`dot-glasses.css:65-72`) styles the `<a class="back" href="/">&#8592;</a>`
  link used on every sub-screen that has a back arrow (`Messages.razor:7`, `Leads.razor:11`,
  `Settings.razor:15`, `FailedRecords.razor:11`) but also sets no `text-decoration`, so the arrow
  glyph itself renders underlined.
- Every other anchor styled as a button (`<a class="dg-btn dg-btn-ghost">`/`<a class="dg-btn
  dg-btn-primary">` — Home's Messages/Settings links, Leads' convert link, ConsultationForm's
  Cancel link, FailedRecords' "Fix & re-send" link) is already correct, because `.dg-btn` itself
  carries `text-decoration: none`. This is the same class of bug as the Admin Portal round's ticket
  03 (bare unstyled elements skipping the shared button/link reset), just on two different classes.

**Desired behavior:**
`.dg-action-tile` and `.dg-top-strip .back` both get `text-decoration: none;` added, matching
`.dg-btn`. No visible underline on any Field App link.

**Key interfaces:**
- `src/DotGlasses.App/wwwroot/css/dot-glasses.css:139-150` (`.dg-action-tile`)
- `src/DotGlasses.App/wwwroot/css/dot-glasses.css:65-72` (`.dg-top-strip .back`)

**Acceptance criteria:**
- [ ] The four Home action tiles render with no underline, in the normal and `:hover`/`:active`
      states.
- [ ] The back arrow on Messages, Leads, Settings, and Failed Records renders with no underline.
- [ ] No other link's appearance changes.

**Out of scope:**
- A full re-audit of every anchor in the app beyond these two classes — the scan for this ticket
  covered every `<a class=` in `src/DotGlasses.App/Pages/**/*.razor` and found no other offender.
