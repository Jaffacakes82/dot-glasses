## Agent Brief

**Category:** enhancement
**Summary:** Add a self-service account settings page for Admin Portal users

**Current behavior:**
There is no page where a signed-in Admin Portal user can view or update their own account
details (e.g. change their password) after initial sign-up. The only related screen, Set
Password, is a one-time flow reached from an invite link, not a general-purpose settings page.

**Desired behavior:**
A signed-in user can reach a settings page (e.g. from account/profile navigation) to change their
own password and update any other basic self-managed account details.

**Key interfaces:**
- A new self-service account page, reusing the existing Identity password-change infrastructure
  that already backs Set Password rather than duplicating it.

**Acceptance criteria:**
- [ ] A signed-in user can navigate to a settings page from somewhere reachable in the standard
      nav (e.g. a user menu).
- [ ] From that page, the user can change their own password (current password required).
- [ ] The page is reachable by any authenticated user, not gated behind an admin-only policy —
      this is self-service for any signed-in user, not an admin function.

**Out of scope:**
- Editing other users' accounts — that's User Directory's existing `Users.ManageInScope`
  functionality, unrelated to this self-service page.
- Adding account fields beyond password change unless the reporter specifies more.
