## Agent Brief

**Category:** enhancement
**Summary:** Add an admin-controlled Toolkit content surface (eye disease chart + tele-
optometrist contact) to the Field App

**Current behavior:**
The Field App's Settings/Toolkit area has no eye disease chart and no tele-optometrist contact
link, and there is no admin-side control surface to manage this kind of Toolkit content at all.

**Desired behavior:**
The Field App Toolkit displays an eye disease chart and a tele-optometrist contact action (for
now, a request form and/or WhatsApp number/link); both are controlled from the Admin Portal by
DGI, following the same admin-controlled-content pattern used elsewhere (e.g. Reference Data),
not hardcoded.

**Key interfaces:**
- An admin-editable content surface for Toolkit items (at minimum: an image/document reference
  for the eye chart, and a contact link/number for the tele-optometrist action), consumed by the
  Field App's Toolkit screen.

**Acceptance criteria:**
- [ ] DGI-level admins can set/update the eye chart asset and the tele-optometrist contact link/
      number from the Admin Portal without a code change.
- [ ] The Field App Toolkit screen displays the current admin-configured content.
- [ ] Field App users with no connectivity still see the last-synced Toolkit content, consistent
      with the app's existing cache-last-known-good pattern for reference data.

**Out of scope:**
- The actual eye-chart artwork/content and real tele-optometrist number — that's a content/
  data-entry task for DGI once this mechanism exists, not part of building it.
- A richer tele-optometry booking/video flow — "request form + WhatsApp number" is explicitly
  interim scope, per the reporter.
