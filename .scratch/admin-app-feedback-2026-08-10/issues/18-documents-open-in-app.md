## Agent Brief

**Category:** enhancement
**Summary:** Documents should open within the Field App, not launch an external browser

**Current behavior:**
Document links in the Field App currently open in the phone's browser rather than within the
app.

**Desired behavior:**
Opening a document from within the Field App keeps the user inside the app's own UI (an in-app
viewer, or equivalent in-app presentation), rather than switching to a separate browser app.

**Key interfaces:**
- Wherever document links are rendered in the Field App — the link/navigation target needs to
  route to an in-app view rather than an external browser context.

**Acceptance criteria:**
- [ ] Tapping a document link in the Field App displays the document without leaving the
      installed PWA/app context.
- [ ] Behavior is confirmed consistent across the platforms the Field App is actually used on,
      since in-app viewing constraints can differ by platform (iOS vs Android PWA).

**Out of scope:**
- Adding new document types/content — this only changes how existing document links are
  presented.
