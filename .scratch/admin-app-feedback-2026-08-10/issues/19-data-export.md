## Agent Brief

**Category:** enhancement
**Summary:** Add data export to the Event History, Organisations, and Custom Orders screens

**Current behavior:**
No screen in the Admin Portal offers any form of data export. Event History, Organisations, and
Custom Orders are all view-only lists today.

**Desired behavior:**
Each of the three screens gains an export action that produces a downloadable file (e.g. CSV) of
the currently-listed rows, respecting whatever hierarchy scoping and filters are already applied
to that screen's view (a user should never be able to export rows outside their own data scope,
or rows excluded by their current filter selection). Wherever the exported data includes lead or
customer information, the export **must** include the `ConsentGiven` field as one of the
exported columns — this is a binding requirement, not optional follow-up, agreed alongside the
original decision to defer export.

**Key interfaces:**
- Event History's existing query/filter parameters should drive the export the same way they
  drive the on-screen list — no separate, divergent query path.
- Wherever a `Lead` or `Sale` (or anything derived from them) appears in an export, the row must
  carry `ConsentGiven`.
- Organisations and Custom Orders exports should respect the same `IHierarchyScoped` data-scoping
  rules already enforced on those screens' normal queries.

**Acceptance criteria:**
- [ ] Event History has a working export producing a file with the currently-filtered rows,
      including `ConsentGiven` for any lead/customer-derived row.
- [ ] Organisations has a working export of the currently-listed rows, scoped to the caller's own
      subtree.
- [ ] Custom Orders has a working export of the currently-listed rows, scoped to the caller's own
      subtree.
- [ ] A user cannot export rows they could not otherwise see on screen (scoping/filter parity is
      enforced server-side, not just hidden in the UI).

**Out of scope:**
- Export formats beyond a single simple tabular format (e.g. no PDF/Excel-specific formatting
  requested).
- Scheduled/automated exports — this is an on-demand, user-triggered action only.
- Adding export to any screen not named above.
