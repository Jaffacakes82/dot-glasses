# 07 — Open decisions from the access audit

**Status:** needs-triage
**Category:** enhancement

> *This was generated by AI during triage.*

The access audit (ticket 03) found no leak, but surfaced two things that need a decision rather
than a fix:

1. **A retail point `User` can convert a Lead to a Sale in the Admin Portal**, inside their own
   scope. Lead conversion requires only sign-in, by design. Restricting it to `Admin` changes the
   role model.
2. **A user with no assignment is invisible in the Admin Portal** — not listed in User Directory or
   the assign picker for anyone, a DGI admin included — so that state cannot be repaired from the
   portal. A user normally always keeps one assignment, but the state can arise outside the
   application (for example a database clear-down).

Also noted by review, not yet actioned: the Field App route gate treats an expired token as signed
out, so a technician whose token expires while offline can no longer open Settings or Failed
records until they can sign in again; and three rule messages quote Field App labels that read
slightly differently on the Admin Portal's lead conversion form.
