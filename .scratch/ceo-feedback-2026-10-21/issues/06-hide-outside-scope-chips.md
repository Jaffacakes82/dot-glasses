# 06 — Hide "Outside your scope" in the User Directory

**Status:** ready-for-agent
**Category:** enhancement
**Blocked by:** None — can start immediately

> *This was generated by AI during triage.*

Feedback (marked "probably not important now but if it's easy"): the User Directory's
Organisations column shows an "Outside your scope" chip for each of a user's assignments the
viewer can't see. "It should filter out any 'outside of scope' to avoid clutter and confusion."
A user with several such assignments shows the chip several times.

## Agent Brief

**Category:** enhancement
**Summary:** The User Directory list shows only the organisations the viewer can see.

**Desired behavior:**
- The Organisations column lists only in-scope organisations. No placeholder chip, no count.
- The Edit user page keeps its existing "plus N organisations outside your scope" line — there it
  explains why the role is read-only, which the list doesn't need.
- A user with no assignment at all (only reachable from outside the app, listed for DGI-level
  callers only) still shows its existing empty-state text.

**Key interfaces:**
- `UserAdminService` — `OutsideScopeOrgName` names the hidden orgs in the list it returns.
- `Views/UserDirectory/Index.cshtml` — renders `user.Scope` as chips.

**Acceptance criteria:**
- [ ] A user with one assignment in the viewer's scope and two outside shows exactly one chip.
- [ ] No "Outside your scope" text appears anywhere on the list.
- [ ] The Edit page's hidden-org count is unchanged.
