Feedback: "If only 1 options auto select the lens coating." The screenshot is a Sale on a lens set
whose chosen lens comes in Photochromic only: the Coating list shows that one unticked box and
"Choose at least one coating." A Coating set needs at least one coating, so the only option is
the only valid answer.

## Agent Brief

**Category:** enhancement
**Summary:** When a lens choice offers exactly one coating, a Coating set has it ticked.

**Desired behavior:**
- Wherever a Coating set is required (a Sale; a Lead that orders), if the offered coatings for
  the chosen lens(es) are exactly one, it is ticked as soon as the lens choice settles. The
  technician can still see it; unticking it is allowed and gives the usual error.
- Applies when the lens choice changes too: moving to a lens with one offered coating ticks it
  (through the existing reconcile step, not a second path).
- Not for a single Coating preference (it's optional), and not when the Coating set is locked
  from an ordered Lead.
- The Admin Portal's lead conversion form does the same, so both write paths agree.

**Key interfaces:**
- `ConsultationForm.razor` — `ReconcileCoatings`, which already reconciles the selection when
  the lens changes; `CoatingSelection.Reconcile`.
- If the rule belongs in `Rules` (`LensSets` / `CoatingSelection`) so both forms share it, put it
  there rather than repeating it in a view script (CLAUDE.md: a script reads what the server
  rendered from Rules).

**Acceptance criteria:**
- [ ] Choosing a lens that offers one coating ticks it; saving without touching coatings
      succeeds.
- [ ] Choosing a lens that offers two or more leaves the selection as today.
