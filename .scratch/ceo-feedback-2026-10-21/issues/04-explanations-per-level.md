# 04 — Page explanations that fit the reader's level

Type: grilling
Status: needs-triage
Blocked by: 03

## Question

Which explanatory text on the Admin Portal should change with the reader's level and role, and
what should each reader see?

## Context

- Feedback: "For users at lower organisational levels, I can still see the same explanations
  that a DGI admin and user would see. It should change the message to only what's relevant for
  me." The screenshot is the Organisations intro, seen by a User at a Retailer/distributor: it
  explains that DGI is the root, how to model a diocese, and how to name retail points — none of
  which that reader can act on.
- Other screens carry similar text, e.g. the User Directory's footer note ("An admin only sees
  history for users at or below their own scope…").

## Points to settle

- An inventory of every explanatory paragraph across the seven screens, and for each: who needs
  it (DGI admin, lower admin, User).
- Hide text or reword it? A reader who can't create organisations needs a one-line "what this
  page shows", not modelling advice.
- Blocked by 03, because what a User can do at each level decides what they need explained.
